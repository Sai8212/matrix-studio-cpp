What is a Matrix?

In simple words, a matrix is numbers arranged neatly in rows and columns, like a grid or table. Each number inside is called an element. Matrices let us organize and work with many numbers at once instead of handling each one separately.

Real-World Applications

  • Computer Graphics Rotating, scaling, and translating 3D models and viewport projections.
  • Engineering Solving large systems of linear equations in circuit and structural design.
  • Physics Describing state transformations, wave equations, and quantum states.
  • Machine Learning Representing tensor datasets, neuron weight matrices, and embedding vectors.

Core Anatomy of a Matrix

Think of a matrix as a rectangular array or table composed of horizontal rows and vertical columns:

• Row: A horizontal line of elements running from left to right.
• Column: A vertical line of elements running from top to bottom.
• Element: Each individual number positioned at row i and column j.
• Order (m × n): Expresses dimensions where m is the number of rows and n is the number of columns (total elements = m × n).
Row vs Column

Rows go across horizontally; columns go down vertically. Indices are always written as (row, column).

Order of Matrix

Written as 'm × n'. Example: a 2×3 matrix contains 2 rows and 3 columns (6 total elements).

Notation A[i][j]

Capital letters denote whole matrices. A[i][j] specifies the single element at row i, column j.

Matrix Operations Guide

Mathematical rules, dimensional constraints, and algorithm specifications

Addition (A + B)

Formula: C[i][j] = A[i][j] + B[i][j]
Rule Both matrices must have identical order
Condition rows(A) == rows(B) && cols(A) == cols(B)
Resulting Order Same order (m × n)
Example:
[ 1 2 ] + [ 5 6 ] = [ 1+5 2+6 ] = [ 6 8 ]
[ 3 4 ] [ 7 8 ] [ 3+7 4+8 ] [ 10 12 ]
×

Multiplication (A × B)

Formula: C[i][j] = Σ (A[i][k] * B[k][j])
Rule Columns of A must equal Rows of B
Condition cols(A) == rows(B)
Resulting Order rows(A) × cols(B)
Example:
[ 1 2 ] × [ 5 6 ] = [ (1*5 + 2*7) (1*6 + 2*8) ] = [ 19 22 ]
[ 3 4 ] [ 7 8 ] [ (3*5 + 4*7) (3*6 + 4*8) ] [ 43 50 ]
ᵀ

Transpose (Aᵀ)

Formula: C[j][i] = A[i][j]
Rule Universal: works on any matrix
Condition None (swaps row/col axes)
Resulting Order cols(A) × rows(A)
Example (2×3 to 3×2):
[ 1 2 3 ]ᵀ = [ 1 4 ]
[ 4 5 6 ] [ 2 5 ]
[ 3 6 ]

Formula: C[i][j] = A[i][j] - B[i][j]
Rule Both matrices must have identical order
Condition rows(A) == rows(B) && cols(A) == cols(B)
Resulting Order Same order (m × n)
Example:
[ 5 6 ] - [ 1 2 ] = [ 5-1 6-2 ] = [ 4 4 ]

Matrix Operations System

An educational and scientific application designed to master fundamental linear algebra concepts and execute high-performance matrix operations including Addition, Multiplication, and Transpose.

Object-Oriented Programming (OOP) Architecture

Original C++ Design Principles Preserved

1. Encapsulation

The matrix grid dimensions (rows, cols) and internal 2D storage (std::vector<std::vector<int>>) are strictly private. External components can only interact through validated getters and setters.

2. Operator Overloading

Matrix classes support natural mathematical syntax directly via operator+ and operator*. Complex row/column multiplications are encapsulated cleanly within operator methods.

3. Separation of Concerns

Mathematical calculations and validation logic are completely independent of the presentation and UI layers, ensuring stability, testability, and zero regression during visual redesign.

Technologies Used

• Core Mathematical Engine: C++ (OOP classes, operator overloading, strict dimension validation).
• Liquid Glass Interface: Modern HTML5, Vanilla CSS3 (Liquid Glass, backdrop-filter, dynamic ambient orbs, micro-animations).
• Platform Support: Windows native executable (Win32 / Edge App Mode) and universal browser workspace.
